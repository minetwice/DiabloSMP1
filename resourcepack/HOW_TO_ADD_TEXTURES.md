# How to Add Textures for DiabloSMP Resource Pack

## Style Required (exactly like your screenshot)

- Square frame with glowing border
- Unique glowing symbol in the center
- Pixel art style
- 16x16 or 32x32 PNG recommended

## Folder Structure

Put all stone textures here:

```
resourcepack/assets/diablosmp/textures/item/stones/
```

## Required Files (create these PNGs):

| File Name              | Suggested Design                          |
|------------------------|-------------------------------------------|
| infernal_core.png      | Red/orange fire eye or flaming core       |
| abyssal_shard.png      | Dark cyan swirling void / eye             |
| earthquake_relic.png   | Golden cracked earth / rock symbol        |
| tempest_orb.png        | Light blue wind swirl / cloud             |
| shadow_fang.png        | Dark gray/black fang or shadow eye        |
| radiant_prism.png      | Bright yellow/white shining prism         |
| frostbite_crystal.png  | Ice blue crystal / snowflake              |
| thunderbolt_core.png   | Purple electric bolt                      |
| bloodmoon_gem.png      | Dark red blood drop / moon                |
| natures_wrath.png      | Green leaf / vine / nature eye            |
| phantom_echo.png       | Ghostly white/gray spirit                 |
| chaos_fragment.png     | Multi-color chaotic swirl                 |
| dragonheart_scale.png  | Dark green dragon scale / heart           |
| voidwalker_stone.png   | Black + purple void portal                |
| celestial_star.png     | White/gold shining star                   |

## Cooldown Font Textures

Put these in:
```
resourcepack/assets/diablosmp/textures/font/
```

- `cooldown_bar.png` (empty/partial bar)
- `cooldown_bar_full.png` (full ready bar)
- `stone_icon.png` (generic stone icon for middle)
- `question_mark.png` (when no stone absorbed)

## After Adding Textures

1. Zip the entire `resourcepack` folder
2. Rename to `DiabloSMP_RP.zip`
3. Put it in your server's resource pack or use `/resoucepack` command / server.properties

Models are already linked via CustomModelData 1000-1014.
