# DiabloSMP Stone Textures Needed

Create **16x16** or **32x32** PNG textures in this exact style (like the purple eye & blue bubbles example):

- Square frame with glowing border
- Center has a unique glowing symbol/icon for each stone
- Slight glow / bloom effect
- Pixel art style

## Required files (put in `assets/diablosmp/textures/item/stones/`):

1. `infernal_core.png`          → Red/Orange fire eye or flame core
2. `abyssal_shard.png`          → Dark cyan / void eye or swirling abyss
3. `earthquake_relic.png`       → Golden rocky symbol / cracked earth
4. `tempest_orb.png`            → Light blue swirling wind / cloud
5. `shadow_fang.png`            → Dark gray / black fang or shadow eye
6. `radiant_prism.png`          → Yellow / white shining prism
7. `frostbite_crystal.png`      → Ice blue crystal / snowflake
8. `thunderbolt_core.png`       → Purple electric bolt / spark
9. `bloodmoon_gem.png`          → Dark red blood drop / moon
10. `natures_wrath.png`         → Green leaf / vine / nature eye
11. `phantom_echo.png`          → Ghostly white / gray spirit
12. `chaos_fragment.png`        → Multi-color chaotic swirl
13. `dragonheart_scale.png`     → Dark green dragon scale / heart
14. `voidwalker_stone.png`      → Black + purple void portal
15. `celestial_star.png`        → White / gold shining star

Also create for cooldown bars (in `assets/diablosmp/textures/font/`):
- `cooldown_bar.png`
- `cooldown_bar_full.png`
- `stone_icon.png` (generic)
- `question_mark.png`

Style reference: the two items you showed (purple eye frame + blue bubbles frame).
